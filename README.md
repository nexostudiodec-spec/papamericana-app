# PAPAMERICANA

Aplicación web de comercio electrónico para PAPAMERICANA.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL)

## Desarrollo local

```bash
npm install
npm run dev
```

Configura las variables de entorno de Supabase en el entorno local y en el proveedor de despliegue:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

No incluyas claves privadas ni secretos en el repositorio.
